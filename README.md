# מסילות · דף המידע הקהילתי

אתר הניוזלטר החודשי של קיבוץ מסילות – React + Vite + Tailwind CSS, בעברית מלאה (RTL), מותאם קודם כל לטלפון.

## הרצה מקומית

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # בנייה לתיקיית dist
```

## העלאה לאוויר (דרך GitHub)

1. מעלים את התיקייה כמאגר חדש ל-GitHub.
2. **Vercel**: Add New → Project → בוחרים את המאגר → Deploy. (הגדרות ברירת המחדל של Vite מתאימות; `vercel.json` כבר דואג לכתובות כמו `/2026/september`.)
3. **Netlify**: Add new site → Import from GitHub → בוחרים את המאגר. (`netlify.toml` כבר מוגדר.)

> GitHub Pages: אפשר, אבל אם האתר יושב תחת תת-תיקייה (`username.github.io/masilot-newsletter/`), יש לשנות ב-`vite.config.js` את `base` ל-`'/masilot-newsletter/'`. הבנייה כבר יוצרת `404.html` כדי שכתובות פנימיות יעבדו.

## איך מוסיפים דף מידע חדש (בלי לגעת בקוד)

1. מעתיקים את `src/data/issues/2026-09.js` לקובץ חדש, למשל `2026-10.js`.
2. משנים בו: `month: 10`, `hebrewMonth: 'אוקטובר'`, `issueNumber`, וכל הטקסטים, התמונות והקישורים.
3. יוצרים תיקיית תמונות `public/issues/2026-10/` ומפנים אליה (`const IMG = 'issues/2026-10/'`).
4. ב-`src/data/issues/index.js` מייבאים את הקובץ ומוסיפים אותו למערך `ALL_ISSUES`.

זהו. הגיליון החדש יופיע בעמוד הראשי, בכתובת `/2026/october` ובארכיון.

### מבנה התוכן

- `hero`, `greeting`, `highlights` (מה חדש החודש), `quickJump` (כפתורי קפיצה)
- `sections` – כל מדור עם `layout`:
  - `cards` – כרטיסים עם תקציר וכפתור "לקריאה מלאה"
  - `mazal` – ברכות מזל טוב
  - `letter` – מכתב ארוך עם גלריה (מש״א, ענף הצומח)
  - `stories` – גלריית תמונות עם כיתובים (חינוך)
  - `teams` – כרטיסי צוותים (ועדת תרבות)
  - `kudos` – פינת הפרגון
  - `links` – כפתורי "הישארו מחוברים"
- לכל פריט אפשר להוסיף: `image`, `gallery`, `contacts` (טלפונים לחיצים), `links`, `schedule`, `timeline`, `original` (צפייה במסמך המקורי).

## מצב בדיקה

הוסיפו `?review=1` לכתובת (למשל `https://.../?review=1`) כדי לראות סימונים צהובים של "לבדיקה" – מקומות שבהם הטקסט במקור לא היה ברור או שחסר מידע. בגרסה הרגילה הסימונים לא מוצגים.

### פריטים לבדיקה בגיליון ספטמבר 2026

- **ארבעת כפתורי "הישארו מחוברים"** (לוח אירועים, אתר מסילות, וואטסאפ, תקנונים) – ב-PDF שיוצא מ-Canva הכתובות לא נשמרו. יש להדביק אותן בשדה `url` במדור `links`. עד אז הכפתורים מוצגים כ"הקישור יעודכן בקרוב".
- **השיר "גם השנה"** (לאה גולדברג) מעמוד השער לא הועתק לאתר. אם יש רשות לפרסם, הדביקו את השורות ב-`poem.lines`.
- "להוכיר" (ברכת מנהל הקהילה), "נעיצת דום" (ענף הצומח), "לפנוות" (הנצחת איתמר) – הושארו כמו במקור.
- עדכון המינהלת מ-16.9 – הועתק מתמונה של מסמך; בסעיף 1 יש רווח במקום סימן פיסוק.
